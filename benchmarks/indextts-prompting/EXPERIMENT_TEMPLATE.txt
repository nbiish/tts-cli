Goal: produce THREE final audio outputs, each backed by factual prompting info
and a run timestamp, so the operator can decide which path to standardize on.

Three variants:

================================================================================
§1. FACTUAL PROMPTING SURFACE (fixed — do not edit)
================================================================================
Model: IndexTTS-2.5 — autoregressive zero-shot TTS, GPT backbone (~0.8B),
      flow-matching mel decoder, BigVGAN vocoder. Output 22.05 kHz.
Languages: ZH, EN, JA, ES, AR.
Emotion (Python):  8-float vector [happy, angry, sad, afraid, disgusted,
                   melancholic, surprised, calm] — mixable, continuous.
Emotion (audio.cpp): --emotion <name>  one of the 8 names above (coarse, single).
Speed (Python):   duration_factor 0.5-2.0  (>1 slower, <1 faster).
Speed (audio.cpp): --speaking-rate <float>, --duration-seconds,
                   --target-duration-seconds, --reference-duration-seconds.
Pronunciation (Python ONLY): <word|reading> inline tags — Pinyin / CMU / Kana.
Pitch/Energy (audio.cpp ONLY): --pitch-shift <float>, --energy-scale <float>.
Voice clone: reference clip sets TIMBRE only; emotion is disentangled.
Limitation: long text is segmented; prosody does NOT cross segment boundaries.
Cold start: ~43s (GGUF/Metal), ~142s (Python/MPS). Both unload on exit.

================================================================================
§4. WHAT TO TRY / VARY (instructions for exploration)
================================================================================
1. EMOTION SWEEP (audio.cpp): run --emotion with each of happy/angry/sad/afraid/
   disgusted/melancholic/surprised/calm on the SAME text+voice. Listen for which
   names the Q8 path renders cleanly vs which collapse. Record the winners.
2. EMOTION VECTOR MIX (Python): on the same text, compare a single-axis vector
   [1,0,0,0,0,0,0,0] vs a mix [0.5,0,0,0,0,0.2,0,0.3]. Note whether the mix
   reads more human — this is the Python path's main advantage.
3. SPEED SWEEP (both): rate 0.9 / 1.0 / 1.1 on the same text. Find the rate
   where the fast path stays intelligible for short summaries.
4. PRONUNCIATION (Python only): take a prompt with a proper noun the model
   misreads, add <word|reading>, compare before/after. This is Python-only and
   the strongest reason to keep the --quality tier.
5. REFERENCE CLIP: try a 5s vs 15s reference; a noisy vs clean one. Confirm the
   model-card claim that timbre (not emotion) is what the reference controls.
6. SEGMENTATION: feed a 600-char prompt vs a 150-char one. Listen for the
   prosody break at the segment boundary (documented limitation).
7. CROSS-LINGUAL: clone a ZH reference speaking EN text, and vice versa.
